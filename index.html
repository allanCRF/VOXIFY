Conectar ao Spotify

Esta é uma aplicação pessoal e não oficial. A conexão usa OAuth PKCE: você autoriza os acessos na página do Spotify, sem fornecer sua senha a este arquivo.

Para autenticação real, publique este HTML em um endereço HTTPS (ou execute localmente em http://127.0.0.1). Arquivos abertos diretamente com file:// e pré-visualizações dentro do ChatGPT não são adequados para o login OAuth.
Endereço para cadastrar como Redirect URI

Passos: 1. Acesse Spotify for Developers e crie um aplicativo. 2. Ative o uso da Web API, cadastre exatamente o Redirect URI acima e salve. 3. Insira o Client ID e conecte sua conta. Sua conta precisa ter Spotify Premium para um aplicativo pessoal em modo de desenvolvimento.

O Client ID fica salvo somente neste navegador. As credenciais OAuth são mantidas na sessão deste navegador. Não inclua Client Secret neste aplicativo. Nunca hospede esta versão em um site de terceiros não confiável.

Compatibilidade com comandos de voz

Use o Chrome no Android ou outro navegador com suporte a Web Speech API e permissão de microfone. Se o navegador não suportar voz, os mesmos comandos funcionam por texto. A transcrição pode ser processada pelo serviço de reconhecimento de fala do navegador.
